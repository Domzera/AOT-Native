# Projeto AOT-Native 
O sigunificado de AOT é (Ahead-Of-Time).
Este é um projeto de uma API feito em AOT - Native, é um CRUD de usuários. Tem validação de campos e está pronto para você usar como base em algum projeto.

O prjeto foi feito com Banco de Dados PostgreSql.

Foram usados C# e PostgreSql como principais tecnologias.

Arquitetura simples com Interfaces e Repositórios.

Você pode fazer o clone com o comando
```sh
git clone https://github.com/Domzera/AOT-Native.git
```
E depois

```sh
dotnet build
dotnet run
```
